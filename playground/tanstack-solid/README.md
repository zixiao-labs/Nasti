# Native Solid Start

This private workspace uses Nasti's built-in Solid JSX compiler and native
TanStack Start adapter. It has no Vite dependency.

See [the shared integration guide](../tanstack-react/README.md) for installation,
commands, architecture, validation and known limits. Application dependencies
are declared here directly; the shared workspace source is imported through
`@nasti-toolchain/tanstack-shared`, not a root-hoisted dependency.
